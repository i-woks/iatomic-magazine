# iAtomic Magazine

A production-ready Persian RTL scientific magazine website for the iAtomic brand, built with React, Cloudflare Workers, D1, R2, and KV.

## Project Structure

- `frontend/` — Public website and admin panel (React + Vite + Tailwind + shadcn/ui)
- `api/` — Backend API and worker (Hono + Drizzle ORM + D1 + R2 + KV)
- `database/migrations/` — D1 SQL migrations
